01 / Quick start

まず使う

LyraStageはライブラリを中心に使います。最初は曲を1つ追加して再生できれば十分です。

  1. 曲を追加する。
    左下の「ファイル追加」または「フォルダ登録」から、手元の音楽・動画をライブラリへ追加します。
  2. ライブラリから曲を選ぶ。
    カードまたはリストの曲を選ぶと中央ステージと下部プレイヤーがその曲へ切り替わります。
  3. 再生する。
    下部中央の再生ボタンを使います。歌詞がある曲は右パネルから歌詞表示へ切り替えられます。
  4. 必要になった機能だけ開く。
    YouTube、歌詞設定、オフライン、録音、キー確認などは後から使えます。

通常インストール版とPortable版では保存場所が異なります。 どちらでもライブラリ、設定、コメント、オフラインキャッシュを利用できます。Portable版はフォルダごと移動する前提です。

02 / Library

ライブラリを整理する

表示と並び順

ライブラリはカード表示とリスト表示を切り替えられます。並び順は手動、追加順、タイトル、アーティスト、最近などから選べます。

  • 手動ではカード／行をドラッグして並び替えられます。
  • Music / Videoのフィルター中でも、手動並び替えは表示範囲の安全な境界を保って保存します。
  • 検索・スマートコレクション・非手動並び順では、曖昧な並び替えを保存しません。

ライブラリプロフィール

用途ごとにライブラリプロフィールを分けられます。共有用プロフィールを作り、個人用とは別に曲やコメントを扱うこともできます。

お気に入り / あとで見る / 再生履歴

左サイドバーからすぐ開けます。再生履歴はライブラリの曲を探し直す補助として使えます。

03 / YouTube

YouTubeを再生する

ライブラリ画面の検索欄は、保存済みライブラリとYouTube検索を同じ流れで扱います。保存済みの同一候補があれば、ライブラリ側を上に表示します。

  1. 曲名、アーティスト名、またはYouTube URLを検索欄へ入力します。
  2. 保存済みライブラリ候補を確認し、その下のYouTube結果から必要な動画を選びます。
  3. 再生だけなら追加せず開けます。保存したい場合はライブラリへ追加します。

再生はYouTube IFrame、direct stream、必要時のFFmpeg fallbackを使い分けます。再生準備中は状態を表示し、同じ動画のURL解決を重複して走らせません。

リンクをコピーしてすぐ再生

設定で「コピーしたYouTubeリンクを検出」とグローバルショートカットを有効にすると、LyraStage起動中に Ctrl + Alt + L でクリップボードのYouTubeリンクを追加せず再生できます。

04 / Lyrics

歌詞・モーション歌詞

右パネルの「歌詞」では同期歌詞を一覧表示できます。中央ステージをモーション表示にすると、現在の歌詞を大きく表示します。

歌詞候補

オンライン候補が見つかっても自動適用はしません。候補の案内を確認して、使う歌詞をユーザーが選びます。候補順は曲の長さとの一致を重視します。

タイミング調整

「歌詞が音より遅い → 早める」「歌詞が音より先に出る → 遅らせる」の案内に沿って同期タイミングを調整できます。

長い間奏

現在の長い歌詞行は、長い間奏中でも不自然に消えず、穏やかな待機モーションで残ります。次の歌詞時刻に到達すると自然に切り替わります。

05 / Playback

再生を歌いやすく調整する

曲ごとの再生調整から、再生速度、キー、ボーカル低減を設定できます。歌詞や録音と同じ再生位置を基準に動きます。

  • 再生速度: 練習時のテンポ変更に使用します。
  • キー: 半音単位の調整に使用します。
  • ボーカル低減: 対応する再生経路でセンター成分を抑える補助機能です。

再生方式によって利用できる処理能力は異なります。LyraStage内部ではBackend capabilityとして区別し、対応していない加工を無理に適用しません。

06 / Offline

オフラインキャッシュ

保存済みYouTube曲は、有効なオフラインキャッシュがあればオンライン経路より先に利用します。現行のYouTubeキャッシュは音声用です。

自動取得のタイミング

自動キャッシュは再生開始と同時には動きません。8秒間の安定再生後にキューへ入り、再生・録音が止まっていて、ユーザー操作も落ち着いているときだけ低優先度で開始します。

前景操作を優先

再生やユーザー操作が再開した場合は、前景処理を優先します。自動取得は1件ずつ動きます。

07 / Full only

録音・Take・MIX

Full版の機能です。 ライブラリの曲から録音ワークスペースを開き、原曲をガイドにしながら歌声を録音できます。

  1. 録音したい曲を選び、録音ワークスペースを開きます。
  2. マイクと必要な録音範囲を確認します。「原曲を聴きながら録音」を使う場合は、録音開始前に元の再生経路を復元します。
  3. 録音するとTakeとして残ります。録り直しても以前のTakeをすぐ削除しません。
  4. MIX画面でTakeを比較し、必要な部分を採用して仕上げます。

部分録り直しや「この部分を使う」では既存Takeを保持します。高度な編集では自然なクロスフェード、既存BPM/拍アンカーを使ったスナップ、歌唱解析の重ね表示も利用できます。

08 / Full only

キー・テンポ・歌唱解析

Full版の機能です。 録音した声と原曲の歌唱範囲を合わせ、キーやテンポ差を確認できます。

キー確認

録音波形を原曲で実際に歌が始まる位置から終わる位置へ合わせます。必要に応じて範囲の端をストレッチし、長さの差をテンポ推定にも利用します。

音域測定

「自分の音域を測る」からガイド測定を開けます。基準音に合わせて発声し、歌いやすい音域確認の補助に使います。

ビート

自動解析に加え、手入力BPM、タップ、現在の拍を基準にしたタイミング調整ができます。

09 / Organize

プレイリスト・コメント・書き出し

通常プレイリストは曲順をドラッグして変更できます。ライブラリからプレイリストへドラッグするとコピー、プレイリスト間で Shift を押しながら移動すると移動として扱います。

サイドバーのプレイリスト

プレイリスト自体もサイドバー内で並び替えられます。

タイムコメント

コメントは再生位置に紐づけて残せます。時刻は送信ボタンを押した瞬間ではなく、実際に文字入力を始めた再生位置を基準にします。

右クリック書き出し

ライブラリ曲のコメントとプレイリストは、右クリックメニューからJSONへ書き出せます。書き出しは保存済みデータを変更しません。

10 / Appearance

外観を変える

設定 → 表示 / 背景 / 歌詞から変更します。外観は明るさ、色、背景を分けて考えます。

表示モード

Dark / Light / Windows設定に合わせるSystem。

カラースキン

Purple / Blue / Green / Rose / Amber。DarkとLightそれぞれに適した組み合わせを使います。

背景

なし / グラデーション / 画像 / キャラクター。画像はローカルファイルを選びます。

作業画面

録音、MIX、キー診断、解析では装飾背景を弱め、作業面を読みやすくします。

11 / External control

Stream Deck・YouTubeリンク連携

Stream Deck

設定 → OBS・Stream Deck連携で外部操作APIを有効にすると、配布フォルダの StreamDeck にあるVBSをStream Deckの「開く」アクションへ割り当てられます。

外部操作APIは 127.0.0.1 のみで待ち受け、LANやインターネットへ公開しません。

YouTubeリンク

クリップボード監視はYouTube URLだけを判定し、それ以外のクリップボード内容をLyraStageへ保存しません。アプリを終了すると監視とグローバルショートカットも終了します。

12 / Data

データ・共有・バックアップ

個人データ

ライブラリ、設定、コメント、履歴、録音などはローカル領域で扱います。通常インストール版とPortable版では保存先の境界を分けています。

ライブラリ共有

ライブラリプロフィールは書き出し・取り込みができます。既存曲は再利用し、既存プレイリストや既存コメントを一方的に上書きしない安全側の取り込みを行います。

プロフィール移行

共有ライブラリやLyraStageプロフィールを使って別環境へ移す場合は、取り込み前に対象と保存先を確認してください。

13 / Update

LyraStageを更新する

通常インストール版は起動時に公開GitHubの更新専用チャネルを確認します。GitHubログインやTailscaleは不要です。

  1. 新しい版がある場合、LyraStageが更新可能であることを表示します。
  2. 「更新内容を見る」で変更点を確認します。
  3. 「更新を準備」を押すと更新ZIPを取得し、URL、サイズ、SHA-256、Ed25519署名を検証します。
  4. 検証済みになったら「LyraStageを終了して更新」を押します。ユーザーの許可なしに勝手に置換しません。

初回インストール用Setupは公開更新リポジトリに置きません。初回Setupは配布元から受け取る運用です。

14 / Support

困ったとき

まず確認する

  • アプリを終了して再起動する。
  • YouTubeだけの問題なら、オンライン再生かオフラインキャッシュかを確認する。
  • 通常インストール版なら設定 → LyraStageのアップデート → 「更新を確認」で最新版を確認する。

不具合を報告する

設定 → 不具合・改善報告からGitHubの報告画面を開けます。Version、Build、Editionなど基本環境だけを自動入力し、曲名、URL、録音内容、認証情報は自動入力しません。

診断ZIP

「診断ZIPを作る」で調査用ZIPを作成できます。自動送信はしません。中身を確認して、必要な場合だけ報告へ添付してください。

起動できない場合

配布フォルダの START_LYRASTAGE_DEBUG.bat を使うと、通常起動より詳しい確認ができます。Windowsのセキュリティ設定を無効にすることを解決策にはしません。

迷ったら、ライブラリへ戻る。

LyraStageはライブラリを入口にしています。曲を選び直せば、再生、歌詞、録音、解析の対象もその曲へ揃います。使わない機能は開かなくて構いません。
