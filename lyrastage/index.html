LyraStage

手持ちの曲とYouTubeをひとつのライブラリへ。歌詞を見て、キーやテンポを確かめ、必要なら録音してMIXまで進められる音楽プレイヤーです。

What you can do

再生から歌うところまで、ひとつにつなぐ。

ライブラリを中心に、再生、歌詞、オフライン、録音、解析へ移動できます。必要な機能だけを使っても構いません。

♪

音楽・YouTubeライブラリ

ローカル音源とYouTubeの曲を同じライブラリで管理。検索結果では保存済みの曲を優先し、プロフィールやプレイリストで整理できます。

LY

同期歌詞・モーション歌詞

同期歌詞をサイドパネルでも中央ステージでも表示。歌詞候補は自動適用せず、内容を確認してから選べます。

↕

キー・テンポ調整

再生速度、キー、ボーカル低減を曲ごとに調整。Full版では録音した歌声からキーやテンポを確かめるワークフローも利用できます。

●

録音・Take・MIX

Full版では原曲を聴きながら録音し、Takeを残して部分採用やMIXへ。録音済みTakeを壊さず編集を進めます。

↧

オフラインキャッシュ

YouTube再生のオフライン用音声キャッシュに対応。自動取得は安定再生後・再生停止中・アイドル時に限定し、前景操作を優先します。

⌘

外部操作

Stream Deck向けのローカル操作APIや、コピーしたYouTube URLを扱うショートカットに対応。外部操作APIは127.0.0.1だけで待ち受けます。

Library first

曲を探して、そのまま次の操作へ。

カード／リスト表示、手動並び替え、スマートコレクション、プレイリスト、再生履歴を1つのサイドバーから扱います。プレイリスト間のドラッグではコピー／Shift移動を使い分けられます。

データは勝手に外へ送りません。

ライブラリ、履歴、録音、設定は利用形態に応じたローカル領域へ保存します。診断ZIPやGitHub報告も自動送信せず、ユーザーが確認してから扱います。

Dark / Light / System

明るさとカラースキンを分けて選択。Purple / Blue / Green / Rose / Amberの5系統を用意し、背景画像・グラデーション・キャラクター背景も別に調整できます。

コメントと書き出し

再生位置に紐づくコメントを残し、曲コメントやプレイリストを右クリックからJSONへ書き出せます。共有時も保存データを直接書き換えません。

更新を安全に確認

通常インストール版は公開更新チャネルを自動確認。更新ZIPのURL、サイズ、SHA-256、Ed25519署名を検証し、ユーザーが許可してから更新します。

困ったときもアプリから

設定から不具合報告、改善提案、診断ZIP作成へ進めます。次版では、同じガイドをアプリ内の「ヘルプ・使い方」から開けるよう準備しています。
